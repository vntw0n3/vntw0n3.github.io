PropEdge

A sports player-prop board for NBA, WNBA, NFL and MLB. It compares lines across about 20 sportsbooks and shows fair-value probabilities for each prop.

Built: a Python pipeline that pulls stats and odds, projects each player, strips the bookmaker margin to get fair prices, and publishes the board, rebuilt automatically five times a day. It measures its own hit rate and says plainly where it can't predict.

  • Python
  • GitHub Actions
  • Cloudflare Workers
  • Monte Carlo simulation
  • Claude Code

03 / process

How a project runs

  1. 01

    Scope

    You describe the problem. I write a spec: who it's for, what they do first, and what happens when something goes wrong.

  2. 02

    Tickets

    The spec becomes a short list of small, testable tickets, so you can see progress and change direction early.

  3. 03

    Build & test

    Each ticket is built with Claude Code, then reviewed and tested before the next one starts.

  4. 04

    Ship

    Your site goes live, and you get the code plus a README that explains how to update it.
